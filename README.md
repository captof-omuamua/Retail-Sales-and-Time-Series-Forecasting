# Retail Sales and Time Series Forecasting

Retail sales exploration, forecasting models and LSTM sequence prediction.

| Notebook | What it covers | Stage |
| --- | --- | --- |
| [02_retail_sales_forecasting.ipynb](02_retail_sales_forecasting.ipynb) | Retail sales exploration, holiday features, regressor comparisons and submission CSV generation. | Project experiment |
| [64_lstm_sequence_prediction.ipynb](64_lstm_sequence_prediction.ipynb) | A small Keras LSTM experiment for predicting the next value of a numeric sequence. | Learning experiment |

## Running these notebooks

pandas, NumPy, SciPy, scikit-learn, seaborn, Matplotlib and pandasql for retail forecasting; TensorFlow/Keras for the sequence example. Supply the retail CSV inputs referenced in the notebook.

Open one notebook in Colab or Jupyter, read its setup cells, set the input paths, and then run the sections you need. Training and network operations are not run automatically by this repository.

## About this collection

These notebooks are organised from an existing Colab archive. The table identifies project experiments, prototypes and learning exercises. Dataset files and model weights are supplied separately. GPU training and external-data workflows were not rerun during preparation.
